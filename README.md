# Numpy-Student-Grade-Analytics

A beginner-friendly data analysis project built with **NumPy**.

This project simulates a student database using **NumPy Structured Arrays** and performs common data analysis operations such as sorting, filtering, normalization, and searching.

It was created as a practice project while learning NumPy.

---

## Features

- Generate random student datasets
- Calculate average scores
- Sort students by any course
- Find the best student
- Find the worst student
- Search students by ID
- Display Top 10 students
- Display Bottom 10 students
- Remove students below the class average
- Normalize scores using Z-score normalization

---

## Dataset Structure

Each student contains the following fields:

| Field | Type |
|-------|------|
| id | int |
| age | int |
| math | float |
| physics | float |
| english | float |
| avg | float |
